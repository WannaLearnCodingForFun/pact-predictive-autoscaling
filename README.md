# PACT

Predictive Autoscaling with Control-Theoretic enforcement, for Docker container pools.

Implementation of the system described in *Deterministic Predictive Auto-Scaling of Docker Containers Using Temporal Convolutional Resource Forecasting and Model Predictive Control.*

Work through `CURSOR_SPEC.md` for the phase-by-phase build rules. This repository is the implementation of that spec.

## Setup

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

Figure generation (pandas, matplotlib):

```bash
pip install -e ".[viz]"
```

ONNX inference needs `onnxruntime` (installed with the core extra). If it is
missing, `OnnxForecaster` raises `ImportError` with an install hint rather than
failing at import time.

## Checks

```bash
ruff check pact tests scripts make_figures.py
mypy pact tests scripts
pytest
```

## Datasets (D1, D2, D3)

The exporter never invents FIFA or Bitbrains rows. Download the traces yourself,
then point `scripts/download_traces.py` at the local files.

**D1 — 1998 FIFA World Cup HTTP.** Request-level log from the Internet Traffic
Archive: <https://ita.ee.lbl.gov/html/contrib/WorldCup.html>. Place a request
log (plain text or `.gz`, one unix timestamp per line, or `t count`) on disk
and parse it into 5 s buckets, 7-day subset:

```bash
python scripts/download_traces.py --fifa data/raw/fifa.log
```

**D2 — Bitbrains GWA-T-12 `fastStorage`.** Grid Workloads Archive trace
(5-minute samples): <http://gwa.ewi.tudelft.nl/datasets/gwa-t-12-bitbrains>.
Resampling to 5 s is **linear interpolation, not measurement**. Pass a local
CSV:

```bash
python scripts/download_traces.py --bitbrains data/raw/fastStorage.csv
```

**D3 — synthetic bursts** (step, ramp, sawtooth, impulse) are generated by the
same script without extra files. `results/dataset_summary.csv` records measured
durations and sample counts from whatever traces were actually loaded.

## Figures

After `python -m pact.eval.runner` (or the ablation/hpsearch exporters) has
written `results/*.csv`:

```bash
python make_figures.py --results results --out figures
```

`make_figures.py` reads the section 9.3 column names and refuses missing or
empty CSVs.
